# Project Instructions

## Stack
- Node.js
- TypeScript
- React
- PostgreSQL
- MySQL

## Rules
- Use TypeScript for all code. Never use the `any` type.
- Use the Zod library for input validation.
- When creating an Express HTTP endpoint, write integration tests for it using Mocha.

## Commands
- `npm run dev` — run the app in development mode
- `npm run test` — run tests
