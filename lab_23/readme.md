# Lab 23 — Express API Hello World

Minimal Node.js Express API that returns a JSON greeting.

## Setup

```bash
cd lab_23
npm install
```

## Run

```bash
npm start
```

Development with auto-restart:

```bash
npm run dev
```

## Try it

```bash
curl http://localhost:3000/
```

Expected response:

```json
{ "message": "Hello, World!" }
```

Optional: set a custom port with `PORT=4000 npm start`.
