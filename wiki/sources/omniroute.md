# Source summary: OmniRoute

**Raw:** `sources/articles/omniroute.md`

Open-source AI gateway article. See [[entities/omniroute]] for compiled notes and comparison with [[entities/openrouter]].

## Key points

- Single endpoint for hundreds of LLM providers and models
- Handles routing, fallback, rate limits, provider switching, and cost optimization
- Self-hosted under MIT license; integrates with Cursor, Claude Code, Codex, Cline, and similar tools
- Optional capabilities: routing strategies, token compression, memory, guardrails, [[concepts/mcp]], analytics, resilience
